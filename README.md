# GenieAcs Ubuntu 22.04

# Usage
```
sudo su
```
```
git clone https://github.com/solinos-utab/gacs.git
```
```
cd gacs
```
```
chmod +x mdnetacs.sh
```
```
sudo apt-get install dos2unix
```
```
dos2unix mdnetacs.sh
```
```
bash mdnetacs.sh
```
